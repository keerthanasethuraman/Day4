# Student Grade System

A simple and interactive student grading system built with Python and Streamlit. This app allows educators to manage student records, enter scores, calculate totals, and view performance summaries in a clean web interface.

## Features

- Add and manage student records
- Enter assignment, quiz, and exam scores
- Calculate total and average grades
- Track student performance
- Display results in a user-friendly table
- Built with Streamlit for fast deployment and easy use

## Project Overview

This application is designed for classroom or academic use, where instructors may need to:
- Record student data
- Evaluate learner performance
- Compute final grades automatically
- Monitor class progress
